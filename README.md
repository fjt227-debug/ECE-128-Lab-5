ECE 128 Lab 5
The objective of this lab was to design and implement a multi-digit seven-segment display driver that is capable of displaying 4-bit binary coded decimal values on the FPGA’s seven-segment display. This was accomplished via a hierarchical design, where the top module took a 16-bit binary input and passed it onto an anode generator that relayed each 4-digit BCD value to the 7-segment decoder which corresponded to each cathode output. With the designing of a testbench, specific cases were able to be simulated to verify the functionality of the design before it was programmed to the FPGA board. 1.) Compile project: Create 1 .vfile and copy the multisegDriver.v file 2.) Make multisegDriver.v the top file in the hierarchy 3.) Run synthesis and implimentation 4.) Generate Bitstream 5.) Copy the testbench and input under simulation sources 6.) Program the board 7.) Run Simulation to get output waveforms
